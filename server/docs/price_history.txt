States: 
- Product (active)
- ArchivedProduct (out of stock/archived)  
- ArchivedBrokenProduct (price=0/broken)

Transitions:
1. Product → ArchivedProduct (archive)
2. ArchivedProduct → Product (restore)
3. Product → ArchivedBrokenProduct (price becomes 0)
4. ArchivedBrokenProduct → Product (price > 0 again)
5. NEW → ArchivedProduct (OOS threshold)
6. NEW → ArchivedBrokenProduct (price=0)


Pipeline Flow:
1. Crawlers fetch products → save to crawler DBs
2. Merge to Stage → Stage has latest data  
3. Merge Stage → Prod (archives missing products)
4. Run history command → Creates history for:
   - All ACTIVE products in Prod
   - All ARCHIVED products (just archived in step 3!)
   
Result: Complete price timeline for ALL products!
